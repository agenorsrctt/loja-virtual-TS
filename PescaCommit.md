# PESCA — COMMITS

### Padrão

**1 commit = 1 alteração lógica completa.**

### Fluxo

```text
Alterar → Testar → Commit → Próxima tarefa
```

### Tipo de commit

```text
feat: nova funcionalidade
fix: correção
refactor: reorganização
docs: documentação
```

### Exemplo

```bash
git commit -m "feat: adiciona criação de produtos"
```
