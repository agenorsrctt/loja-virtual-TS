# Texto para publicação no LinkedIn

Meu projeto full stack está no ar: ASR Systems! 🚀

Desenvolvi um sistema de gestão de vendas e estoque com cadastro de clientes e produtos, dashboard e controle de acesso por empresa.

Usei TypeScript, Node.js e Express no backend, HTML, CSS e JavaScript no frontend, SQLite no desenvolvimento local e Turso na nuvem. A aplicação está publicada na Vercel e pode ser instalada como PWA em navegadores compatíveis.

Um dos principais desafios foi manter venda e estoque consistentes: calcular os valores no servidor, desfazer alterações quando uma operação falha e impedir que um cancelamento devolva o estoque duas vezes.

Também implementei autenticação com JWT, hash de senhas com bcrypt e testes automatizados para acesso, vendas e isolamento entre empresas. Levar o projeto até a publicação trouxe aprendizados sobre variáveis de ambiente, migrações e compatibilidade de dependências.

Aplicativo: https://asr-systems.vercel.app/
Código: https://github.com/agenorsrctt/loja-virtual-TS

O sistema exige autenticação; o README explica como executar localmente e explorar as funcionalidades.

Feedbacks sobre o código e a experiência de uso são bem-vindos!
